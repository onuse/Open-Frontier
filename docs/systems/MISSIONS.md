# Mission System

**Version:** 0.1  
**Status:** Design Phase

---

## Overview

Missions in Open Frontier are **generated by system needs**, not quest NPCs. Two sources:
1. **Station-generated missions:** Automated response to inventory shortages
2. **Player contracts:** Posted by other players (Phase 3+)

This document covers:
- Mission generation rules
- Reward calculation
- Mission types
- Completion and failure conditions

---

## No Mission NPCs

**Critical design point:** There are no human NPCs giving quests.

Missions come from:
- Station automation detecting critical needs
- Players posting contract work

This maintains the "automated idiocrasy" theme—the infrastructure is asking for help, not characters.

## Station-Generated Missions

### Critical Delivery Missions

Automatically generated when station inventory falls below critical threshold:

```typescript
interface StationNeed {
  stationId: string;
  good: string;
  currentInventory: number;
  consumptionRate: number;     // Units per day
  criticalThreshold: number;   // Percentage of capacity
  timeToDepletion: number;     // Hours until empty
}

function checkMissionGeneration(station: Station): Mission | null {
  for (const good of station.requiredGoods) {
    const inventory = station.inventory[good];
    const capacity = station.storageCapacity[good];
    const consumption = station.getConsumptionRate(good);
    
    const inventoryPercent = inventory / capacity;
    
    // Critical mission: below 10% capacity
    if (inventoryPercent < 0.10) {
      return generateCriticalDeliveryMission(station, good, inventory, consumption);
    }
    
    // Bulk mission: below 50% capacity
    if (inventoryPercent < 0.50) {
      return generateBulkTransportMission(station, good, inventory, consumption);
    }
  }
  
  return null;
}
```

### Mission Generation Formula

```typescript
function generateCriticalDeliveryMission(
  station: Station,
  good: string,
  currentInventory: number,
  consumptionRate: number
): Mission {
  // Calculate shortage
  const shortage = station.storageCapacity[good] - currentInventory;
  const requestedQuantity = Math.min(shortage, consumptionRate * 3); // 3 days worth
  
  // Calculate time to depletion
  const hoursToEmpty = currentInventory / (consumptionRate / 24);
  const deadline = new Date(Date.now() + hoursToEmpty * 3600 * 1000);
  
  // Calculate reward
  const basePrice = getTradeGoodBasePrice(good);
  const urgencyMultiplier = calculateUrgencyMultiplier(hoursToEmpty);
  const reward = basePrice * requestedQuantity * urgencyMultiplier;
  
  return {
    id: generateMissionId(),
    type: 'critical_delivery',
    issuer: station.id,
    good: good,
    quantity: requestedQuantity,
    destination: station.id,
    deadline: deadline,
    reward: reward,
    status: 'available'
  };
}

function calculateUrgencyMultiplier(hoursToEmpty: number): number {
  // More urgent = higher multiplier
  if (hoursToEmpty < 24) return 3.0;      // Critical
  if (hoursToEmpty < 72) return 2.0;      // Urgent
  if (hoursToEmpty < 168) return 1.5;     // Moderate
  return 1.2;                              // Low urgency
}
```

## Mission Types

### 1. Critical Delivery

**Generated when:** Inventory < 10% capacity

**Characteristics:**
- High urgency
- Tight deadline (based on time to depletion)
- High reward multiplier (2-3x base price)
- Failure consequences: Station suffers shortage

**Example:**
```json
{
  "id": "mission_crit_001",
  "type": "critical_delivery",
  "issuer": "Mars_Olympus_Station",
  "good": "oxygen",
  "quantity": 500,
  "destination": "Mars_Olympus_Station",
  "deadline": "2025-11-02T18:00:00Z",
  "deadlineHours": 48,
  "reward": 75000,
  "status": "available"
}
```

### 2. Bulk Transport

**Generated when:** Inventory < 50% capacity (but not critical)

**Characteristics:**
- Lower urgency
- Flexible deadline (or no deadline)
- Lower per-unit reward (1.2-1.5x base price)
- Economic opportunity, not emergency

**Example:**
```json
{
  "id": "mission_bulk_002",
  "type": "bulk_transport",
  "issuer": "Earth_Station_Alpha",
  "good": "electronics",
  "quantity": 1000,
  "destination": "Mars_Olympus_Station",
  "deadlineHours": null,
  "reward": 60000,
  "status": "available"
}
```

### 3. Sample Return (Future)

**Generated when:** Station needs rare/exotic items for research

**Characteristics:**
- Exploration-focused
- Long timelines
- High rewards for hard-to-find items
- May require travel to distant systems

### 4. Rescue/Recovery (Future)

**Generated when:** Player ship stranded (out of fuel, damaged)

**Characteristics:**
- Generated by player distress beacon
- Time-sensitive (life support limited)
- Reward from rescued player or insurance
- Cooperative gameplay element

## Mission Rewards

### Reward Philosophy

Rewards should be **economically logical**, not arbitrary game balance numbers.

**Formula:**
```
reward = (base_price × quantity × urgency_multiplier) + distance_bonus
```

**Components:**

1. **Base Price:** Market value of the good
2. **Quantity:** How much needs to be delivered
3. **Urgency Multiplier:** How desperate the need is
4. **Distance Bonus:** Extra pay for long hauls

### Reward Examples

**Critical oxygen delivery to Mars:**
- Base price: 100 credits/unit
- Quantity: 500 units
- Urgency: 3.0x (critical)
- Distance bonus: 10,000 credits (Earth to Mars)
- **Total reward: (100 × 500 × 3.0) + 10,000 = 160,000 credits**

**Bulk electronics to Mars:**
- Base price: 5,000 credits/unit
- Quantity: 20 units
- Urgency: 1.2x (low)
- Distance bonus: 5,000 credits
- **Total reward: (5,000 × 20 × 1.2) + 5,000 = 125,000 credits**

### Balancing

**Early game:** Small cargo capacity = take small missions  
**Mid game:** Larger ships = bulk transport becomes viable  
**Late game:** Interstellar missions with massive rewards

## Mission Lifecycle

### 1. Generation

Station automation creates mission when threshold reached:
```typescript
const mission = generateMission(station, good);
addToMissionBoard(station, mission);
broadcastMissionAvailable(mission); // Notify players
```

### 2. Acceptance

Player docks at station and accepts mission:
```typescript
function acceptMission(player: Player, mission: Mission): Result {
  // Check player has cargo capacity
  if (player.cargoCapacity < mission.quantity) {
    return { error: 'Insufficient cargo space' };
  }
  
  // Reserve mission for player
  mission.status = 'accepted';
  mission.acceptedBy = player.id;
  mission.acceptedAt = new Date();
  
  // Add to player's active missions
  player.activeMissions.push(mission.id);
  
  return { success: true };
}
```

### 3. Completion

Player delivers goods to destination:
```typescript
function completeMission(player: Player, mission: Mission, station: Station): Result {
  // Check player has the goods
  if (player.cargo[mission.good] < mission.quantity) {
    return { error: 'Insufficient cargo' };
  }
  
  // Check deadline (if applicable)
  const now = new Date();
  if (mission.deadline && now > mission.deadline) {
    return completeLateMission(player, mission, station);
  }
  
  // Transfer cargo to station
  player.cargo[mission.good] -= mission.quantity;
  station.inventory[mission.good] += mission.quantity;
  
  // Pay reward
  player.credits += mission.reward;
  
  // Update mission status
  mission.status = 'completed';
  mission.completedAt = now;
  
  return { success: true, reward: mission.reward };
}
```

### 4. Failure

Mission fails if:
- Deadline passes and not completed
- Player abandons mission
- Player ship destroyed with mission cargo

```typescript
function failMission(player: Player, mission: Mission): void {
  mission.status = 'failed';
  mission.failedAt = new Date();
  
  // Consequences
  // - No reward
  // - Station's shortage worsens
  // - Reputation loss (future feature)
  
  // Mission may regenerate with higher urgency
  if (mission.type === 'critical_delivery') {
    regenerateMission(mission.issuer, mission.good);
  }
}
```

## Player Contracts (Phase 3+)

### Posting a Contract

Players can post missions at stations:

```typescript
interface PlayerContract {
  id: string;
  type: 'player_contract';
  poster: string;            // Player ID
  description: string;       // Freeform text
  good: string;
  quantity: number;
  destination: string;
  collateral: number;        // Posted by contractor (locked)
  reward: number;            // Paid to contractor
  deadline: Date;
}

function postContract(
  player: Player,
  good: string,
  quantity: number,
  destination: string,
  reward: number,
  deadline: Date
): Result {
  const collateralRequired = reward * 0.5; // 50% of reward
  
  // Check player can afford collateral
  if (player.credits < collateralRequired) {
    return { error: 'Insufficient credits for collateral' };
  }
  
  // Lock collateral
  player.credits -= collateralRequired;
  
  // Create contract
  const contract: PlayerContract = {
    id: generateContractId(),
    type: 'player_contract',
    poster: player.id,
    good,
    quantity,
    destination,
    collateral: collateralRequired,
    reward,
    deadline
  };
  
  addToMissionBoard(destination, contract);
  
  return { success: true, contract };
}
```

### Collateral System

Prevents griefing and ensures good faith:

**Poster:**
- Locks 50% of reward as collateral
- If contractor completes, poster pays reward + collateral returned
- If contractor fails, collateral forfeit

**Contractor:**
- No upfront cost
- Must deliver goods by deadline
- Gets reward if successful
- Loses nothing if fails (except time)

**Example:**
- Player A posts: "Deliver 200 water to Europa Station, 75k reward"
- Player A locks 37.5k collateral
- Player B accepts and delivers
- Player B gets 75k reward
- Player A gets 37.5k collateral back
- Total cost to Player A: 75k (as intended)

## Mission Difficulty Scaling

No artificial scaling. Difficulty is **emergent:**

**Easy missions:**
- Short distance (Earth to Moon)
- Common goods (water, oxygen)
- No deadline pressure

**Hard missions:**
- Long distance (Earth to Neptune)
- Rare goods (exotic items)
- Tight deadlines (fuel race)

Players self-select based on ship capability and skill.
